# ☕ Coffee Access Premium

Aplicación web moderna, accesible y premium para explorar, aprender y solicitar más de **30 variedades de café** del mundo.

![Coffee Access Premium](https://img.shields.io/badge/WCAG-2.2%20AA%2FAAA-brightgreen)
![Vanilla JS](https://img.shields.io/badge/Vanilla-JS-yellow)
![HTML5](https://img.shields.io/badge/HTML-5-orange)
![CSS3](https://img.shields.io/badge/CSS-3-blue)

## 🚀 Demo rápida

Abre `index.html` directamente en tu navegador. No requiere servidor ni dependencias.

## ✨ Características

- **30+ variedades de café** con descripción, historia, preparación y perfil de sabor
- **Búsqueda inteligente** por nombre, país, tipo de grano e intensidad
- **Lectura por voz** (SpeechSynthesis API) con control de velocidad
- **Favoritos** persistidos en LocalStorage
- **Historial de pedidos** con confirmación animada
- **Dashboard** con estadísticas y gráficos animados
- **Modo oscuro / claro / alto contraste**
- **Escalado de fuente** (4 niveles)

## ♿ Accesibilidad (WCAG 2.2)

- Skip link visible al navegar con teclado
- `aria-live`, `aria-modal`, `aria-pressed`, roles semánticos completos
- Trampa de foco en modales
- Navegación 100% por teclado
- Soporte `prefers-reduced-motion`
- Contraste AAA cuando es posible
- Áreas táctiles ≥ 44px
